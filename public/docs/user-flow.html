Nodal Control — User Flow

Updated 2026-04-17. End-user navigation and action flows for the current app.

1. Top-level entry + landing by role

flowchart TD
    START([App opens]) --> COOKIE{Has session cookie?}
    COOKIE -->|no| LOGIN[login page]
    COOKIE -->|yes| LANDING{Role check}

    LOGIN -->|enters name + PIN| AUTH{PIN valid?}
    LOGIN -->|taps Join Project| JOIN_PAGE[login/join page]
    LOGIN -->|taps Forgot PIN| FORGOT[login/forgot-pin]

    AUTH -->|yes| LANDING
    AUTH -->|wrong, under 10| LOGIN
    AUTH -->|10 wrong attempts| LOCKED[Account locked 15 min]
    LOCKED --> LOGIN

    LANDING -->|admin / manager / crew| DASH[Dashboard]
    LANDING -->|user-only memberships| MYEQ[My Equipment]

    JOIN_PAGE -->|scans QR or enters PIN + name| JOIN_FLOW[joinProject action]
    JOIN_FLOW -->|new user| SET_PIN[Create personal PIN]
    JOIN_FLOW -->|existing user| LOGIN
    SET_PIN --> LOGIN

    LOCK_CARD -->|click Unlock| UNLOCK[Unlock user action]

3. User-only flow

flowchart TD
    LOGIN[Login] -->|signs in| MYEQ[My Equipment]
    MYEQ --> CARDS[Equipment cards]
    CARDS -->|tap a panel card| PS[Panel Studio]
    PS -->|back arrow| MYEQ

    PS --> EDIT{Edit keys?}
    EDIT -->|yes request mode| SUBMIT[Submit changes]
    SUBMIT --> WAIT[Green submitted highlight]
    WAIT -->|polling detects resolution| RESULT{Admin action?}
    RESULT -->|approved| TOAST_OK[Toast: your panel changes are live]
    RESULT -->|denied| TOAST_DENY[Toast: keys denied, revert]

    NAV_BLOCKED[User tries other routes] -->|proxy redirects| MYEQ

4. Change request round-trip

flowchart TD
    CS1[Crew: Panel Studio loaded] --> CS2[Tap key]
    CS2 --> PICKER[Picker opens]
    PICKER --> CS4[Key state changed - yellow]
    CS4 --> CS6[Click Submit changes]
    CS6 --> CS7[Key state submitted - green]
    CS7 --> CS8[Polling every 5s]

    CS8 -->|fingerprint changed| CS9{Any resolutions?}
    CS9 -->|approvals| CS10[Toast: panel changes are live]
    CS9 -->|denials| CS11[Toast: keys denied]
    CS9 -->|mix| CS12[Both toasts]
    CS10 --> CS13[Reset to DB truth]
    CS11 --> CS13
    CS12 --> CS13

    AS1[Admin: Tasks page] --> AS2[Badge shows count]
    AS2 -->|click Tasks| AS3[Tasks list]
    AS3 --> AS5[Click Review]
    AS5 --> AS7[Panel Studio review mode]
    AS7 --> AS8[Toggle approve or deny per key]
    AS8 --> AS9[Click Resolve]
    AS9 --> AS10[resolveChangeRequests action]
    AS10 --> AS11[Approved items update PanelKey]
    AS10 --> AS12[CR status applied or rejected]
    AS11 -.->|crew poll picks up| CS8

5. Pick List / Equipment bulk-add

flowchart TD
    START[User on tab] --> BUTTON[Click plus or Add button]
    BUTTON --> FORM[Card opens with inputs]

    FORM --> INPUTS[ID / Name or Category + Quantity]
    INPUTS --> DECIDE{Which inputs filled?}

    DECIDE -->|Name filled, Pick List| SINGLE[Create 1 named item]
    DECIDE -->|Name blank + ID blank| AUTO[Auto-gen N codes]
    DECIDE -->|Name blank + ID filled| LITERAL[Start at user ID - preserve pad, skip collisions]

    SINGLE --> POST[POST to server action]
    AUTO --> POST
    LITERAL --> POST

    POST --> RESULT{Success?}
    RESULT -->|yes| TOAST_OK[Toast: Added N items]
    RESULT -->|too many collisions| TOAST_ERR[Error toast]

    TOAST_OK --> REFRESH[router refresh]
    REFRESH --> CLOSED[Form closes]

7. Device reachability probing

flowchart TD
    LOAD[Page loads with IPs] --> CACHE{sessionStorage cache}
    CACHE -->|fresh under 10s| INSTANT[Render last-known state]
    CACHE -->|stale or missing| START[Render all white]

    INSTANT --> PROBE[Start probe round]
    START --> PROBE

    PROBE --> PAR[Probe every device in parallel]
    PAR --> FETCH[fetch no-cors]
    PAR --> IMG[img fallback]

    FETCH --> TIMING{Response time}
    IMG --> TIMING
    TIMING -->|25ms or more| REACHABLE[Green]
    TIMING -->|under 25ms| FALSE[Discard - network reject]
    TIMING -->|timed out| UNREACHABLE[White]

    REACHABLE --> SAVE[Save cache and broadcast]
    UNREACHABLE --> SAVE
    SAVE --> PAINT[Update UI]
    SAVE --> REPEAT[Wait 30s]
    REPEAT --> PROBE

    BC[Other tab broadcasts] -.->|skip own probe| SAVE
